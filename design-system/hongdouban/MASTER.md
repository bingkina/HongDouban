# 红豆瓣设计系统

以用户于 2026-10-26 批准的首页方案为准。ui-ux-pro-max 检索匹配了 Dark Mode (OLED) 风格；其通用转化漏斗、默认配色与字体不适合本产品，不采用。

## 产品与视觉

红果短剧的独立评分社区原型。内容优先，电影感与文字阅读并重。只展示真实红果剧集，不提供视频播放。

| 角色 | 值 |

| 页面背景 | #101114 |
| 卡片表面 | #1B1D23 |
| 品牌朱红 | #E5484D |
| 金色评分 | #F4C46B |
| 主要正文 | #F2F0EB |
| 次要正文 | #A3A4AD |

系统中文黑体；推荐标题使用系统宋体。Lucide 单一图标库，原创豆形 SVG 标识。普通品牌按钮使用深朱红与白字；首屏朱红按钮配深色字，确保正文对比度。

## 布局与行为

桌面最大宽度 1280px；六列热播海报，找剧内容配右侧榜单。850px 以下将侧栏移入正文；600px 以下采用两列海报、四项底部导航与底部预览面板。

首页区域：发现、热播、找剧、榜单、剧评、片单。主要按钮至少 44px。真实海报定比预留尺寸；失败显示带剧名占位。固定导航预留安全区和滚动偏移。

## 数据与交互

平台评分明确标记红果评分；本机评分和示例评论单独标记。24 部作品的静态快照不是实时剧库。个人想看、已看、五星评分、短评仅保存在浏览器。没有账号或虚构社区统计。

## 无障碍与动效

正文对比度至少 4.5:1；图标按钮有名称；原生 dialog 管理焦点与 Escape；radio 实现星级评分。支持减少动态效果，图片 hover 仅做轻量缩放。不自动轮播、不自动播放。
